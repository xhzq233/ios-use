## 如何理解 R3

相对保留的 cb R1（134.806 s / 749,286 tokens），本轮更慢、总 tokens 更多；
不能称为 Agent 提速成功。R3 额外读取子页，并出现恢复和大量重复观察；覆盖与
源码候选均不同，不与 R1 混算均值，也不与主页面为主的 CLI 样本做等工作量归因。

候选时间段 Driver 日志包含 DOM 309 次 / 55.590 s、tap 102 次 / 38.047 s、
swipe 8 次 / 20.075 s（1 次失败），没有 waitFor RPC。保留 cb R1 的 DOM 为 63 次。
工具可见区间并集 118.725 s，其余 188.046 s 包含模型生成与调度等，不能称为纯思考时间。
子页阶段从首次调用到最后回包跨 119.438 s；不能直接扣掉它推算“只读主页面”的反事实成绩。

本轮工具文字总计 147,362 B（包含两份文档读取）；最大单项 38,650 B 是安装 App
清单，不是整棵节点 JSON。候选没有整树 JSON 输出，因此 46.3% 的节点体积下降
不能直接映射为本轮 tokens / 耗时收益。修复的功能行为与体积收益已验证，Agent
端收益需要同覆盖样本，当前不追加 trial。
